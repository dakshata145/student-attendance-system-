# Student Attendance Management System

## Project Overview
The Student Attendance Management System is a web-based application designed to simplify and manage student attendance records. It allows users to add student details, mark daily attendance, view attendance history and calculate attendance percentages.

The system provides a simple and user-friendly interface for managing student attendance digitally.

## Objectives
- To maintain student attendance records digitally.
- To reduce manual attendance work.
- To calculate student attendance percentages.
- To provide easy access to attendance information.
- To improve accuracy and efficiency in attendance management.

## Technologies Used
- HTML5 – Structure of the application.
- CSS3 – Styling and user interface.
- JavaScript – Application functionality.
- LocalStorage – Storing student and attendance records.

## Features
1. Add new student details.
2. Display student lists.
3. Mark students as Present or Absent.
4. Select attendance dates.
5. View attendance records.
6. Calculate attendance percentages.
7. Delete student records.
8. Dashboard with attendance statistics.

## Modules
- Student Management
- Attendance Management
- Attendance Records
- Dashboard and Statistics

## Installation and Execution
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open index.html.
5. Right-click and select Open with Live Server.
6. Start adding students and managing attendance.

## Future Enhancements

## Conclusion
The Student Attendance Management System provides an efficient digital solution for maintaining student attendance. It reduces manual work, improves record management and makes attendance monitoring easier.
